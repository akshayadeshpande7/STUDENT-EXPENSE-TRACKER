# Student Expense Tracker

## Overview
Student Expense Tracker is a simple command-line Python application for recording and managing student expenses.

## Features
- Add an expense
- View expenses
- Delete an expense
- Set a monthly budget
- View total expenses and remaining budget
- Show a budget exceeded alert
- Search by category or description
- Validate numeric input

## Technologies
- Python
- Command-line interface
- Lists and dictionaries
- Functions
- Conditional statements
- `for` and `while` loops
- String methods
- Exception handling

## How to Run
1. Install Python 3.
2. Save the program as `main.py`.
3. Open a terminal in the project folder.
4. Run `python main.py`.

## Main Functions
- `add_expense()`
- `view_expenses()`
- `delete_expense()`
- `set_budget()`
- `view_summary()`
- `search_expense()`

## Testing
Test valid and invalid amounts, empty expense lists, valid and invalid delete numbers, budget alerts, and matching/non-matching searches.
