**Project Statement**



Project Title



Student Expense Tracker



Problem Statement



Students make minor expenditures on snacks, travel, and other things. It becomes difficult to track all the expenses and know how much has been spent and on what by the end of the month.



Student Expense Tracker is a simple expense tracker built using Python to enable students keep track of their daily expenses and avoid exceeding a monthly budget.



Scope



The scope of this project is limited to expense and budget tracking of students.



The application is designed to enable the user to



* add expenses



* view all expenses



* delete expenses



* set the monthly budget



* view all expenses against the set budget



* view budget exceeded warning



* search for an expense



* and handle invalid numeric inputs



The application is intended to be a console application and does not require a Graphical User Interface (GUI) or online connectivity.



\## Target Users



The main target audience for this application is college students.



\## High-Level Features



1\. Manage Expenses



All the expenses can be added, viewed, and deleted. The expenses have a field for the amount, category, and description.



2\. Budget Tracking



The set budget can be tracked against the sum of the expenses.



3\. Budget Alert



The application will alert the user when the set budget has been exceeded.



4\. View Totals



The totals for the amount spent and the budget will be viewable in the application.



5\. Search Expenses



The application will enable the user to search for expenses using keywords for categories and descriptions.



6\. Input Validation



The application will handle invalid inputs and numeric values.



\## Input



The application will receive the following as inputs



Menu options



Expense amount



Expense category



Description of the expense



Monthly budget



Search terms



and the index of the expense to be deleted.



\## Output



The application will produce the following outputs



View all the expenses



View the running total



View the set monthly budget



View the remaining budget



View the budget exceeded warning



View search results and



show warning messages for invalid inputs.
